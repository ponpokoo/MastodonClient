# メイン画面の状態管理と責務

メイン画面の4つのタブは、`Route.Timeline` のナビゲーションエントリ内でそれぞれのViewModelを保持します。
タブを切り替えても状態は維持されます。このエントリを削除すると、ViewModelは破棄され、実行中のリクエストもキャンセルされます。

| 管理するViewModel | 担当する処理 |
| --- | --- |
| `MainSessionViewModel` | アカウントの復元・切替・ログアウト、共通設定、フォアグラウンド状態に応じた接続制御、1本のストリーミング接続 |
| `TimelineViewModel` | ホーム・ローカル・連合タイムライン、追加読み込み、更新、サーバーからのお知らせ |
| `SearchViewModel` | 検索語、検索リクエストと検索結果、検索語変更時のキャンセル |
| `NotificationsViewModel` | 通知、追加読み込み、未読件数、通知の既読位置 |
| `OwnProfileViewModel` | 現在のアカウントのプロフィール、プロフィール内のタブ、更新、追加読み込み |
| `StatusActionsViewModel` | 4つのタブで共通する投稿・アカウント操作と、リスト選択画面の状態 |

`HomeTimelineScreen` は各ViewModelの状態を個別に購読し、操作のコールバックを担当するViewModelへ渡します。
すべての状態をまとめた `TimelineUiState` は作りません。
`ProfileContent` はプロフィール表示に必要な範囲に絞った `ProfileUiState` を受け取り、`AccountProfileScreen` でも共用します。
プロフィールの編集とフォロー関係などの管理は、引き続き `AccountProfileViewModel` が担当します。

## セッションと更新通知の共有

`BrowsingSession` は、`MainSessionViewModel` が保持するドメイン層のオブジェクトです。
他のViewModelには、別のViewModelそのものではなく、このオブジェクトを渡します。
セッションのスナップショットにはアカウントと世代番号が含まれます。
別のアカウントへ切り替えた後に元のアカウントへ戻っても、切替前の古いリクエストを再び有効と判断しないための仕組みです。

`SessionScopedViewModel` は、セッションに紐づくリクエストのライフサイクルとイベントの配信を管理します。
スナップショットが変わると、リクエストをキャンセルし、継承先のViewModelの状態を初期化します。
レスポンスを状態へ反映する前には、コルーチンがキャンセルされていないことと、現在のスナップショットが一致することの両方を確認します。
検索語やタブが変わった場合も、その画面内で不要になった古いリクエストをキャンセルします。

ユーザーストリームへの接続は `MainSessionViewModel` だけが行います。
イベントには発生元のセッションのスナップショットを添え、各画面が自分に関係するイベントを受け取ります。
`StatusActionsViewModel` も、同じセッションオブジェクトを通じて成功した操作の変更内容を通知します。
4つのタブはそれぞれの一覧を更新し、その際もブーストされた投稿のタイムライン上の識別情報を維持します。
投稿が削除された場合は一覧から取り除き、通知内のその投稿への参照もクリアします。

このイベント配信経路は、現在のメイン画面のタブ間で状態を同期するためのものです。
永続キャッシュや、アプリ全体のリポジトリの状態を置き換える仕組みではありません。

## 回帰テストと動作確認

単体テストでは、次のケースを検証します。

- アカウント切替・ログアウト後に遅れて届くレスポンス
- 検索のやり直し
- 追加読み込み中のプロフィールのタブ切替
- 追加読み込み中の通知の再取得
- アカウント間で通知の既読位置が混ざらないこと
- すべてのタブへの投稿更新・削除の反映
- フォアグラウンド状態に応じた、1本のストリーミング接続の開始・停止

一部のテスト用リクエストは、意図的にキャンセルを無視します。
これにより、スナップショットの照合やレスポンス反映前の確認が機能することを検証します。

プロジェクトで使用するJDKを設定し、`./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest` を実行します。
実機では、ログイン済みのテストアカウントで、タブ切替、プロフィール編集画面への遷移、設定画面から戻る操作も確認します。
