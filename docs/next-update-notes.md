# 次回更新・リリースメモ

次のベータ版に含める実装の整理用メモ。版番号、公開日、配布APKはリリース作業開始時に確定する。

## 今回までの実装

- 前景中のMastodon Streaming APIによる通知受信と、バックグラウンドの約15分ごとの簡易通知。
  バックグラウンド即時通知は提供しない。
- 通知タブ表示時・アプリ復帰時の自動更新、Streaming受信とのID単位の重複防止、通知元ユーザー画像の表示。
- Android共有メニューからのテキスト／URLと画像の受信、および投稿画面への反映。
- いいね・ブーストの即時UI反映、失敗時のロールバック、画面間の状態同期。
- いいね数が1件以上の投稿で、いいねアイコン長押しから「お気に入りしたアカウント」一覧を表示。
  一覧のアカウントを選ぶとプロフィールへ移動する。

## 実機で確認する項目

- 前景・バックグラウンド遷移時の通知受信、通知元ユーザー画像、通知タブの自動更新。
- 他アプリからのURL共有・画像共有、および投稿画面の入力・添付への反映。
- いいね／ブーストの追加・解除、通信失敗時のロールバック、同一投稿の連続タップ抑止。
- いいねアイコンの長押し、一覧の読み込み・失敗表示、アカウント選択後のプロフィール遷移。

## 次の候補

- 通知欄の既読表現、通知タップ時の詳細動作、スクロール位置保持の追加確認。
- 正式リリース向けUI解説、設定画面構成、デザイン全体の実機確認。
