# 絵文字ピッカー

[UI・機能仕様と共通ルール](../ui-guidelines.md)

投稿へのカスタム絵文字挿入とリアクションで使う絵文字選択の仕様。
操作領域、文字倍率、読み上げ、選択状態の表現は[共通のデザイン方針](../ui-guidelines.md#デザイン方針)に従う。

## 操作名

投稿画面でピッカーを開くボタンとピッカーのタイトル、設定の「投稿画面のボタン順」に表示する名称は「絵文字」とする。
投稿本文下でピッカーを開くボタンとピッカーのタイトルは「リアクション」とする。
投稿画面では選択した絵文字を本文に挿入し、投稿本文下では対象の投稿にリアクションを付ける。

## シートの高さと閉じる動作

シートは半開きを経由せず展開した位置で開く。絵文字一覧の上下スワイプではシートを動かさず、一覧だけをスクロールする。
高さと閉じる操作は[ReactionPickerSheet.kt](../../app/src/main/java/io/github/ponpokoo/mastodonclient/feature/timeline/ReactionPickerSheet.kt)で実装している。以下の値は実装を変更する際の調整値とする。

### 高さの調整値

「すべて」を含む全カテゴリで、画面高を基準に同じ一覧領域を確保する。カテゴリ切替・検索・お気に入りの追加や削除でシートの高さを変えず、件数が少ない場合や0件でも同じ高さを保つ。

| 調整項目 | 現在値 | 実装の対応箇所 |
| --- | --- | --- |
| シート全体の高さ上限の基準 | 画面高の82% | `maxSheetHeight`内の`0.82f` |
| 絵文字一覧の希望高さの基準 | 画面高の58% | `LazyColumn`の`height`内の`0.58f` |
| シートを低くする調整量 | 48 dp | `heightReduction` |
| ステータスバーの下に残す背景の余白 | 48 dp | `maxHeight - statusBarHeight - 48.dp`の末尾の値 |

高さの計算では、`H`を`LocalConfiguration.current.screenHeightDp`による画面高、`A`を`BoxWithConstraints.maxHeight`による利用可能高、`S`をステータスバーの高さとする。いずれもdpで扱う。`A`はボトムシート標準のキーボード回避処理を適用した後の高さである。
`R`は`heightReduction`、`G`は背景の余白とし、現在はどちらも48 dpとする。

```text
絵文字一覧の希望高さ = max(0 dp, H × 0.58 - R)
シート全体の高さ上限 = max(0 dp, min(H × 0.82, max(0 dp, A - S - G)) - R)
```

一覧の実際の高さは、シートの高さ上限からヘッダー・検索欄・カテゴリ列・下部の操作などを除いた範囲に収める。
シートを一律に低くする場合は`heightReduction`を増やし、高くする場合は減らす。この値を一覧の希望高さとシートの高さ上限の両方から差し引き、通常時とキーボード表示時に同じ調整量を適用する。背景の余白`G`は別の調整値として扱う。

キーボードが表示領域を狭める場合は一覧を縮め、シートの上に背景が見える余白を残す。キーボードを閉じると元の高さへ戻す。
浮動キーボードや物理キーボードの利用時など、利用可能高が変わらない場合は高さを維持する。検索欄・カテゴリ列・選択中のカテゴリ名は固定し、保存・削除後の通知は一覧に重ねる。

### 閉じる操作の調整値

シート上部に操作可能であることを示すバーを表示する。バーとタイトルを含むヘッダーから下へ引くとシートが指に追従する。
指を離した時点でシートの下方向への移動量がしきい値以上なら閉じ、しきい値未満なら元の位置へ戻す。閉じる判定は距離で決め、速さによる追加判定は行わない。シートを元の位置より上へは動かさない。

| 調整項目 | 現在値 | 実装の対応箇所 |
| --- | --- | --- |
| 閉じる判定のしきい値 | 76 dp以上 | `dismissThresholdPx`の`76.dp` |
| 元の位置へ戻る時間 | 140 ms | `headerDismissOffset.animateTo`の`tween(140)` |
| バーの表示サイズ・角丸 | 幅32 dp、高さ4 dp、角丸2 dp | `reaction_picker_drag_handle`の`width`・`height`・`RoundedCornerShape` |
| バーを配置する領域の高さ | 24 dp | バーを囲む`Box`の`height(24.dp)` |

ドラッグはバーとタイトルを含むヘッダー全体で受け付ける。ドラッグ中の移動量は`headerDismissOffset`で管理し、`graphicsLayer`の`translationY`へ反映する。閉じる際のアニメーションは`sheetState.hide()`に任せる。
シート標準のドラッグは`sheetGesturesEnabled = false`で無効にし、半開きは`skipPartiallyExpanded = true`で省略する。これらを変更する場合は、絵文字一覧とのスクロール干渉も確認する。
右上に閉じるボタンは置かず、外側タップ、戻る操作、ヘッダーの読み上げ用の閉じる操作でも閉じる。

### 調整後の確認

| 確認する操作 | 確認内容 | 関連する端末テスト |
| --- | --- | --- |
| カテゴリ切替・検索 | 「すべて」、件数の多いカテゴリ、空の履歴・お気に入りで高さと検索欄の位置が変わらない | [ReactionPickerCategoryDeviceTest.kt](../../app/src/androidTest/java/io/github/ponpokoo/mastodonclient/ReactionPickerCategoryDeviceTest.kt) |
| 一覧とヘッダーのスワイプ | 一覧の先頭で下へ引いてもシートは動かない。ヘッダーの短い引き下げは元に戻り、十分に引くと閉じる | 同上 |
| キーボード表示・非表示 | 表示領域が狭まる場合は上側に余白を残して縮め、閉じると高さが戻る。浮動表示などで領域が狭まらない場合は高さを維持する | [SearchInputDeviceTest.kt](../../app/src/androidTest/java/io/github/ponpokoo/mastodonclient/SearchInputDeviceTest.kt) |
| 投稿画面からの選択 | 選んだ絵文字を本文に挿入し、本文の入力を続けられる | [ComposerToolbarDeviceTest.kt](../../app/src/androidTest/java/io/github/ponpokoo/mastodonclient/ComposerToolbarDeviceTest.kt) |

高さ・余白・しきい値だけの変更では固定値を再記述するテストを増やさず、影響する既存テストと実際の表示・操作で確認する。キーボードの確認では、利用可能高を狭める表示方式も対象にする。
文書だけを更新する場合は記載内容・参照先・差分を確認する。検証範囲は[変更範囲に応じた確認](../project-setup.md#変更範囲に応じた確認)に従う。

## 選択一覧とプレビュー

検索欄の直下に、横スクロールできる1列のカテゴリアイコンと、右端に固定したカテゴリ一覧ボタンを置く。
順序は「すべて」「履歴」「お気に入り」「標準」「表情」「しぐさ・記号」、続いてサーバーから取得したカスタムカテゴリとする。
カスタムカテゴリは一覧内の先頭の絵文字の静止画を代表アイコンにし、カテゴリ名がない絵文字は「その他」にまとめる。
カテゴリ列の代表絵文字は高さ24 dpを基準に元の縦横比で表示し、横長の絵文字は必要な幅を取って文字が小さくなるのを防ぐ。
各アイコンの操作領域は高さ48 dp・幅48 dp以上とし、選択中は背景と下線で示す。「標準」は家、「お気に入り」は星アイコンを使う。
カテゴリ名は読み上げに対応し、選択中の名前をアイコン列の下に表示する。
カテゴリ一覧ボタンからは名前付きの一覧を開き、画面外のカテゴリや長い名前も確認・選択できる。

初期選択は「すべて」とする。カテゴリを選ぶとそのカテゴリだけを表示し、検索語とカテゴリの両方で絞り込む。
カテゴリを変えても検索語は保持し、一覧を先頭へ戻す。「すべて」では全カテゴリを検索する。
検索欄は探索と共通の入力部品を使い、文字があるときだけ右端に「×」を表示する。
「×」では変換中の未確定文字も含めて検索語を消去し、選択中のカテゴリと入力フォーカスを保って絵文字一覧を再表示する。
高さの統一、固定する領域、キーボード表示時の扱いは[シートの高さと閉じる動作](#シートの高さと閉じる動作)に従う。
「すべて」の検索語が空の場合は一覧の先頭に履歴を表示し、「履歴」では履歴だけを表示・検索する。
履歴の長押しから確認付きの削除と取り消しができる。履歴が空なら「履歴はまだありません」、検索結果が空なら「該当する絵文字がありません」と表示する。
取得した絵文字の更新で選択中のカスタムカテゴリがなくなった場合は「すべて」へ戻す。

標準・カスタム絵文字は長押しでプレビューを開く。カスタム絵文字はショートコードと拡大画像、標準絵文字は名前と拡大した絵文字を表示する。
「閉じる」の隣に「お気に入りに追加」を置き、登録済みの場合は「お気に入り登録済み」として無効化する。
その下の選択操作は、投稿画面では「この絵文字を挿入」、投稿へのリアクションでは「この絵文字でリアクション」とする。お気に入りの追加だけでは投稿本文への挿入や投稿へのリアクションを行わない。
絵文字選択一覧と長押しプレビューは静止画を使い、APNG再生を適用しない。
投稿本文とリアクション欄での表示は[投稿表示・メディア](status-media.md#日時と投稿の表示内容)を参照する。

## 投稿用の絵文字取得と投稿元切替

カスタム絵文字の一覧は投稿元ごとに背景で取得し、取得完了を投稿ボタンの有効化条件にしない。投稿元切替時は前の一覧をクリアし、切替前の取得結果を反映しない。
投稿画面の入力と投稿元切替の操作は[投稿・下書き](compose-drafts.md#投稿中の操作と投稿元切替)を参照する。

## お気に入りの保存と削除

お気に入りはアカウント別に端末へ保存し、投稿用とリアクション用のピッカーで共有する。アプリを再起動しても保持し、アカウントを削除すると対象の分を削除する。
Unicode絵文字は文字列、カスタム絵文字はショートコードを保存する。登録順に並べ、重複登録と履歴の20件上限による切り捨てを行わない。
サーバーの一覧からなくなったカスタム絵文字も保存は残し、名前で表示して削除できるようにする。
「お気に入り」カテゴリで一覧表示・検索・選択でき、未登録の場合は「お気に入りはまだありません」と表示する。
お気に入りを長押しすると削除確認を開く。キャンセルでは保持し、削除すると保存内容も更新する。削除後の通知から「元に戻す」を選ぶと再登録する。履歴は変更しない。
読み込み失敗時は再試行を表示し、保存失敗時は変更前の一覧とプレビューを保ってエラーを表示する。保存中は追加・削除の二重操作を抑止する。
アカウント切替時にはピッカーの表示状態を破棄し、切替前の読み込み・保存結果を別アカウントへ反映しない。
