# 絵文字ピッカー

[UI・機能仕様と共通ルール](../ui-guidelines.md)

投稿へのカスタム絵文字挿入とリアクションで使う絵文字選択の仕様。
操作領域、文字倍率、読み上げ、選択状態の表現は[共通のデザイン方針](../ui-guidelines.md#デザイン方針)に従う。

## 操作名

投稿画面と投稿本文下でピッカーを開くボタンの名称は「リアクション」に統一する。
ピッカーのタイトルと、設定の「投稿画面のボタン順」に表示する名称も「リアクション」とする。
投稿画面では選択した絵文字を本文に挿入し、投稿本文下では対象の投稿にリアクションを付ける。

## 選択一覧とプレビュー

シートは半開きを経由せず展開した位置で開き、絵文字一覧の上下スワイプでは移動・縮小・閉鎖しない。
シート上部に操作可能であることを示すバーを表示する。バーとタイトルを含むヘッダーから下へ引くとシートが追従し、十分に引いて離すと閉じる。短い引き下げでは元の位置へ戻し、上方向へのスワイプでは閉じない。
右上に閉じるボタンは置かず、外側タップ、戻る操作、ヘッダーの読み上げ用の閉じる操作でも閉じる。

検索欄の直下に、横スクロールできる1列のカテゴリアイコンと、右端に固定したカテゴリ一覧ボタンを置く。
順序は「すべて」「履歴」「お気に入り」「標準」「表情」「しぐさ・記号」、続いてサーバーから取得したカスタムカテゴリとする。
カスタムカテゴリは一覧内の先頭の絵文字の静止画を代表アイコンにし、カテゴリ名がない絵文字は「その他」にまとめる。
カテゴリ列の代表絵文字は高さ24 dpを基準に元の縦横比で表示し、横長の絵文字は必要な幅を取って文字が小さくなるのを防ぐ。
各アイコンの操作領域は高さ48 dp・幅48 dp以上とし、選択中は背景と下線で示す。「標準」は家、「お気に入り」は星アイコンを使う。
カテゴリ名は読み上げに対応し、選択中の名前をアイコン列の下に表示する。
カテゴリ一覧ボタンからは名前付きの一覧を開き、画面外のカテゴリや長い名前も確認・選択できる。

初期選択は「すべて」とする。カテゴリを選ぶとそのカテゴリだけを表示し、検索語とカテゴリの両方で絞り込む。
カテゴリを変えても検索語は保持し、一覧を先頭へ戻す。「すべて」では全カテゴリを検索する。
検索欄は探索と共通の入力部品を使い、文字があるときだけ右端に「×」を表示する。
「×」では変換中の未確定文字も含めて検索語を消去し、選択中のカテゴリと入力フォーカスを保って絵文字一覧を再表示する。
検索欄・カテゴリアイコン・選択中のカテゴリ名を固定し、絵文字一覧だけを縦スクロールする。
絵文字一覧は「すべて」の表示で使う高さを全カテゴリで確保し、切替・検索・お気に入りの追加や削除でピッカー全体の高さを変えない。件数が少ない場合や0件でも同じ高さを保つ。
キーボード表示などで表示可能な高さが減った場合は一覧領域を縮める。キーボードを除いた表示領域でもシートの上に背景が見える余白を確保し、画面上端まで覆わない。キーボードを閉じると元の高さへ戻す。保存・削除後の通知は一覧に重ね、高さを変えない。
「すべて」の検索語が空の場合は一覧の先頭に履歴を表示し、「履歴」では履歴だけを表示・検索する。
履歴の長押しから確認付きの削除と取り消しができる。履歴が空なら「履歴はまだありません」、検索結果が空なら「該当する絵文字がありません」と表示する。
取得した絵文字の更新で選択中のカスタムカテゴリがなくなった場合は「すべて」へ戻す。

標準・カスタム絵文字は長押しでプレビューを開く。カスタム絵文字はショートコードと拡大画像、標準絵文字は名前と拡大した絵文字を表示する。
「閉じる」の隣に「お気に入りに追加」を置き、登録済みの場合は「お気に入り登録済み」として無効化する。
その下に「この絵文字でリアクション」を置く。お気に入りの追加だけでは投稿本文への挿入や投稿へのリアクションを行わない。
絵文字選択一覧と長押しプレビューは静止画を使い、APNG再生を適用しない。
投稿本文とリアクション欄での表示は[投稿表示・メディア](status-media.md#日時と投稿の表示内容)を参照する。

## 投稿用の絵文字取得と投稿元切替

カスタム絵文字の一覧は投稿元ごとに背景で取得し、取得完了を投稿ボタンの有効化条件にしない。投稿元切替時は前の一覧をクリアし、切替前の取得結果を反映しない。
投稿画面の入力と投稿元切替の操作は[投稿・下書き](compose-drafts.md#投稿中の操作と投稿元切替)を参照する。

## お気に入りの保存と削除

お気に入りはアカウント別に端末へ保存し、投稿用とリアクション用のピッカーで共有する。アプリを再起動しても保持し、アカウントを削除すると対象の分を削除する。
Unicode絵文字は文字列、カスタム絵文字はショートコードを保存する。登録順に並べ、重複登録と履歴の20件上限による切り捨てを行わない。
サーバーの一覧からなくなったカスタム絵文字も保存は残し、名前で表示して削除できるようにする。
「お気に入り」カテゴリで一覧表示・検索・選択でき、未登録の場合は「お気に入りはまだありません」と表示する。
お気に入りを長押しすると削除確認を開く。キャンセルでは保持し、削除すると保存内容も更新する。削除後の通知から「元に戻す」を選ぶと再登録する。履歴は変更しない。
読み込み失敗時は再試行を表示し、保存失敗時は変更前の一覧とプレビューを保ってエラーを表示する。保存中は追加・削除の二重操作を抑止する。
アカウント切替時にはピッカーの表示状態を破棄し、切替前の読み込み・保存結果を別アカウントへ反映しない。
