## 投稿と下書き

### 初期設定と公開範囲

新規投稿・返信・自分の投稿編集に対応する。
新規入力を作る時だけ取得済みのサーバー初期公開範囲・引用許可・言語を採用する。未取得なら公開範囲は端末設定、引用許可・言語はサーバーに従う。通信完了を待たず、遅い取得結果は次の新規入力から反映する。
投稿画面の初期公開範囲は、保存済みの設定と一時入力の復元を確認してから表示する。確定前はボタンの場所だけを保ち、仮の公開範囲やアイコンを表示・操作させない。この表示のためにサーバー設定を新しく取得しない。

新規返信は返信先の公開範囲も確認し、復元する下書き・一時入力では保存済みの公開範囲を先に表示する。
設定の「投稿」では項目名を「公開範囲」とし、取得済みの初期公開範囲を選択値に反映する。通常時の補足説明文は置かない。選択肢は公開・ひかえめな公開・フォロワー限定とし、変更はサーバーの初期設定へ保存する。保存中は二重操作を抑止し、応答で保存値を確認できた時だけ選択を確定する。失敗時は元の値を保ち、エラーを表示する。

未取得時は従来の端末設定を表示の代替値に使い、保存成功後の値は次の新規投稿から適用する。
編集中の選択、下書き・一時入力の復元値（デフォルトを表すnullも含む）、既存投稿の編集値を取得結果で補完・上書きしない。投稿単位の選択はサーバーの初期設定を変更しない。引用許可の選択ボタンは設けず、取得済みの初期値を使う。非公開・ダイレクトは自分だけの引用許可として送信する。

投稿元、公開範囲、本文、CW、センシティブ指定、
画像・動画・音声添付、ALT編集、投票、カスタム絵文字挿入、メンション候補を扱う。
カスタム絵文字の選択と一覧の取得・投稿元切替時の扱いは[絵文字ピッカー](emoji-picker.md)を参照する。

### 共有内容の受け取り

Androidの共有メニューでテキスト／URL、画像・動画・音声を共有先として受け取る。
テキスト／URL共有の`ClipData`にあるプレビュー用アイコン・画像は添付しない。`EXTRA_STREAM`で明示された添付は受け取る。
メディアは単一共有と複数共有に対応し、同じURIが複数回渡された場合は1件として扱う。
投稿画面を開いたまま別の共有を受けた場合は、既存入力を一時保持して投稿画面を開き直し、新しい共有内容を反映する。

ログイン済みなら投稿画面を開き、テキストを本文に、対応するメディアを添付に反映する。
未ログインなら共有内容を一時保持し、ログイン完了後に投稿画面を開く。
ログイン済みの共有メディアは投稿画面でサーバー設定などの通信を待つ前にアプリ専用領域へ取り込む。
ALT編集と投稿前確認は通常の添付と同じ扱いにする。未ログインからの共有内容の保持はメモリ上であり、プロセス終了後の復元を保証しない。

### 添付の検証とサーバー設定

各ファイルのMIMEはContentResolverを優先し、不明・汎用型の場合だけファイル名の拡張子から推定する。判別できない形式は添付しない。
文字数、添付上限、対応MIME一覧は投稿元サーバーのInstance APIから取得する。
投稿設定は接続先ごとに5分間メモリへ保持し、v2 Instance APIが404の場合はv1へフォールバックする。
対応MIME一覧が取得できない場合はメディアを送信せず、設定の再取得を表示する。
取り込み済みの共有メディアは再取得後に検証できる。

共有添付を取り消せばテキストだけの投稿を続けられる。
通常の写真選択と共有は共通の検証を通し、対応形式と添付上限を確認してから先行アップロードする。
画像はサーバーの上限まで複数添付できる。動画・音声は1件のみとし、他のメディアとの併用を拒否する。
一部のファイルが非対応・読み取り失敗・上限超過などで添付できない場合は、採用件数と拒否理由・ファイル名を表示する。
下書きの添付も再送前に検証し、非対応になったファイルは削除せず理由を表示して送信を止める。

### 投票・言語・入力操作

投票とメディアは併用不可。投票は最大4択、複数選択に対応し、期間の初期値は24時間。
地球アイコンの言語ボタンから中央ダイアログを開き、先頭に「デフォルト」を固定表示する。デフォルトは言語指定を省略してサーバーに委ね、選択した言語は下書き・一時入力にも保持する。投稿編集では元の言語を引き継ぐ。
「#」ボタンは本文のカーソル位置に半角の#を挿入する。ハッシュタグの入力補完は行わない。
投票期間を選ぶUI、添付の並べ替えUIはない。
画像・動画はシステムの写真選択UIから選ぶ。

音声は他アプリからの共有のみで受け取り、投稿画面に音声選択機能は設けない。

### 添付の表示と先行アップロード

投稿画面の添付は本文入力欄の下に
2列のタイルで配置する。サムネイル・ファイル名・サイズ・削除操作を表示し、
ALTは編集ボタンからダイアログで入力する。入力済みALTはタイル内で1行に要約する。
音声のタイルには音声ファイルのアイコンを表示し、画像サムネイルの読み込みを行わない。
添付後1秒待ってから、メディアを1件ずつ先行アップロードする。送信画像の縮小・再圧縮は行わない。
タイル内に送信率、サーバー処理中、ALT反映中を表示し、失敗時はそのタイルで再試行と詳細確認ができる。

通信の上限は60秒、非同期処理の完了待ちも60秒とする。処理待ち超過は失敗と断定せず、
「再確認」で保持したメディアIDを照会する。エラー詳細と診断ログはHTTPステータスまたは例外の種類に限定する。
投稿時は待機中の送信を開始し、全メディアの処理と最新ALTの反映を待つ。失敗箇所への自動スクロールは行わない。
添付削除・投稿元切替・画面を閉じる際は先行処理をキャンセルする。下書きには投稿元にひもづけた
メディアIDと最新ALT、ローカルファイルを保持し、復元時にIDを確認する。

存在しないIDは元ファイルから再送する。
バーのゴミ箱は確認なしで本文をクリアし、CW・投票・添付と保存済み下書きは変更しない。返信相手のメンションが削除される場合は返信も解除する。

## 投稿中の操作と投稿元切替

投稿中・メディア取り込み中は競合する操作を抑止し、ALT未入力時は設定に応じて確認する。
投稿編集中は投稿元アカウントを切り替えられない。返信中に切り替えた場合は、本文のメンションと入力済みテキストを引き継ぎ、返信先指定と返信元表示を解除する。添付などは切替元の一時バッファに保持し、別アカウントへ送信しない。
返信元のプレビューは同じアカウント・インスタンスで取得済みの投稿を再利用し、投稿設定や絵文字の取得を待たずに表示する。下書き復元などでキャッシュがない場合だけ返信元の投稿単体を取得する。

## 返信の初期公開範囲と宛先

新規返信を開始するときの公開範囲と宛先は次のとおりとする。

- メンション限定（`direct`、画面表示は「指定した相手のみ」）の投稿への返信は、自分の既定公開範囲に関係なくメンション限定を初期値とする。投稿画面での手動変更は可能とする。
- 新規に返信を開始するとき、元投稿の投稿者とメンション相手を本文の宛先へ自動入力する。投稿者を先頭にし、自分自身を除き、重複を取り除く。自分の投稿への返信でも、元投稿のほかのメンション相手を引き継ぐ。

この初期化では、編集中の選択や下書き・一時入力の復元値を上書きしない。公開範囲と宛先の扱いは、[公式Androidの公開範囲初期化](https://github.com/mastodon/mastodon-android/blob/v2.13.4/mastodon/src/main/java/org/joinmastodon/android/fragments/ComposeFragment.java#L1130-L1163)と[宛先入力](https://github.com/mastodon/mastodon-android/blob/v2.13.4/mastodon/src/main/java/org/joinmastodon/android/fragments/ComposeFragment.java#L578-L601)に従う。

## 返信・引用の解除と一時入力

本文から返信相手（元投稿の投稿者）のメンションを削除すると、返信元のプレビューと返信先指定を解除して通常投稿へ切り替える。本文の残り・CW・添付などは保持する。メンションを再入力しても返信は自動で復活しない。メンションを削除しても返信指定を維持する公式の挙動は採用せず、この解除動作を維持する。
リンクによる引用では、本文から引用元の投稿URLを削除・置換すると引用元のプレビューと引用指定を解除する。標準の引用は本文中のURLとは独立しているため、URL削除では解除しない。

返信・引用のカードには「×」を表示し、元の投稿を取得する前でも解除できる。「×」は返信・引用の指定とプレビューだけを解除し、本文のメンションやURL、CW、添付などは保持する。引用を解除するとメディア・投票や投稿元切替の制限も解除する。
解除処理は返信・引用で共通にする。解除前の一時入力を消し、元の投稿の取得を取り消す。解除・下書き呼出・アカウント切替後に古い結果や取得失敗が届いても反映しない。

下書き保存には解除後の指定を記録し、メンションやURLを再入力しても指定は自動で復活させない。
投稿元を切り替える際は現在の入力をそのアカウントの一時バッファへ保持し、切替先の入力を復元する。

## 下書きの保存と呼び出し

**永続下書きは明示的に保存する。自動保存の設定はない。**
画面を閉じるときの入力保持はメモリ上の一時バッファであり、プロセス終了後の復元を保証しない。
保存済み下書きは個別のキーと投稿元で区別し、本文、CW、公開範囲、
言語・引用許可、センシティブ指定、添付ファイル情報とALT、投票を保存する。添付はアプリ専用領域へ取り込む。
保存済み下書きの呼出・削除に対応し、投稿成功時は対応する下書きとバッファを削除する。

保存済み下書きを呼び出した時点で一覧から除き、内容と添付ファイルを編集中の投稿へ移す。
再び下書きに残すには明示保存が必要。再保存時は呼び出した下書きのキーを引き継ぐ。
保存成功後は本文・CW・添付・投票・返信先・引用指定をクリアし、公開範囲や言語などは通常の新規投稿時の設定へ戻す。
保存完了の通知は2秒後に消える。表示中は通知から下書き一覧を開ける。保存失敗時は入力と添付を保持し、エラーを表示する。
保存中は入力変更・投稿・投稿元切替・二重保存を抑止する。

新しく入力して保存した投稿は別の下書きとして残す。

## 下書き一覧

一覧は選択中の投稿元の下書きを更新日時の新しい順で表示する。各項目はアイコンとサーバー名を含むID、本文最大3行、保存日時と添付の種類・件数の順に並べる。
添付がない場合は添付欄を表示しない。投票がある場合は同じ補助行に表示する。
項目のタップで呼び出し、三点メニューまたは長押しから確認付きで削除する。見出しには件数を表示する。
