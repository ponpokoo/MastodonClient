# ADR 0017：端末内ワードミュートを廃止して公式フィルターに集約

- 状態：accepted
- 記録日・採用日：2026-10-12
- 置換元：[ADR 0008](0008-word-mutes-in-notification-lists.md)の端末内ワード保存・表示判定

## 背景と判断

公式フィルターをアプリから管理できる構成になり、端末内ワードミュートとの機能の重複を避けるため、利用者が端末内機能の削除を選んだ。
管理画面・Repository・共有状態・本文/CWの部分一致判定を廃止し、公式フィルターは投稿の`filtered`情報と共通の表示判定で適用する。
管理アカウントの隔離、アカウントのミュート・ブロック、解除の取り消しは維持する。

旧設定の`wordMutes`は未知項目として読み飛ばす。読み込みで他の設定をリセットせず、通常の設定保存時に再シリアライズされるため旧項目は除去される。
削除のためだけの起動時書き込みは追加せず、それまでは旧JSONに残り得るが、表示へは適用しない。
旧ワードをサーバーに自動送信・変換せず、公式フィルターの既存設定と下書きは保持する。

## 代替案と制約

端末限定の用途や未対応サーバー向けに残す案は、管理・判定経路を二重に維持するため採用しない。
公式フィルターv2が使えないサーバーには非対応を表示し、端末内判定へのフォールバックは行わない。
公式フィルターの適用画面をこの削除に伴って拡張せず、Android通知への適用も追加しない。

現在の取得・更新・適用範囲は[サーバー設定調査](../investigations/server-account-settings-sync.md)、画面の仕様は[UIガイド](../ui-guidelines.md#サーバー保存設定と公式フィルター)を参照する。
