# ADR 0005：管理アカウントの隔離とローカルワードミュート

- 状態：accepted
- 記録日・採用日：2026-10-05

## 背景

設定からサーバーのミュート・ブロック一覧を取得・解除し、短時間の取り消しに対応する。
アプリで確認した関係だけでは、他のクライアントで設定した対象を一覧にできない。
ワードミュートはアカウント別の投稿非表示に限定し、端末内で管理する要件になった。

## 決定と理由

管理専用ViewModelが選択アカウント、一覧取得、解除、取り消し、失敗と再試行を担当する。
管理アカウントは投稿元の選択と同様に画面内で選び、閲覧セッションを変更しない。
切替時は要求のキャンセルと世代番号を照合し、A→B→Aでも古い応答を採用しない。
一覧はサーバーから取得し、HTTP Linkヘッダーの内部カーソルを使う。
解除と取り消しは既存TimelineRepositoryの関係変更と共有非表示・キャッシュ除去経路を使う。
ミュートを戻す際は取得済みの通知抑制と残り期限を使い、期限切れは再設定しない。

ワードはWordMuteRepositoryからUserPreferencesStoreへ保存し、セッション別StateFlowで共有する。
共通の表示フィルターで本文の表示テキストとCWを判定し、通知には適用しない。
ワードで隠す投稿は内部一覧・DBから削除しないため、削除や取り消しで保持中の投稿を戻せる。
サーバーのアカウント制限で除去する既存方針は[ADR 0004](0004-account-moderation-invalidation.md)を維持する。

## 代替案と受け入れる制約

- 全体の閲覧セッションを切り替える：管理対象を選ぶだけで背後のタイムラインを初期化するため採用しない。
- サーバーのフィルターへ保存する：他クライアントや通知への適用範囲、サーバー版ごとの互換性が今回の要件を超える。
- ワード一致行をキャッシュから削除する：即座の取り消しに再取得が必要になるため採用しない。

管理一覧は画面内の取得結果であり、定期同期や永続複製は行わない。
期限フィールドがないサーバーでは無期限として復元し、再ブロックで変わったフォロー関係は復元しない。
端末保存のワードはサーバー同期せず、別端末への共有は行わない。
