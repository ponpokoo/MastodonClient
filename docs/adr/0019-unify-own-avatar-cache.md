# ADR 0019：自アカウントのアイコン取得を共通キャッシュへ統合

- 状態：accepted
- 日付：2026-10-25
- [ADR 0011](0011-account-display-synchronization.md)のうち、アイコンの番号付きキャッシュと表示情報同期時の画像再取得を置き換える。認証・表示情報同期の境界は維持する。

自アカウントの表示情報同期は、同じ画像URLでも永続化した更新番号を増やしていた。
この方式では起動・切替・プロフィール取得によるアカウント情報同期が画像再取得につながり、他の表示やAndroid通知のURLキーともキャッシュを共有できない。

自分のアイコンも、共通のURLキー・24時間再検証・旧画像保持・同時取得制限を使う。
アカウント情報の取得・同期は画像を強制更新せず、自プロフィールの引っ張って更新とアイコン編集成功時にだけ、ViewModelからドメインRepositoryを経由して強制再検証を要求する。
明示的な再検証は期限・失敗後の待ちを越えて実行できる。編集前から取得中の同じURLを新しい結果として採用せず、終了後に新たに取得する。
URLごとの成功通知で各表示と拡大画面を更新し、ヘッダーの更新番号と画像の表示所有者は維持する。

アイコン更新番号を認証・投稿者のモデルと保存形式から除く。旧JSONの番号は未知フィールドとして読み飛ばし、既存の認証情報や閲覧DBを初期化しない。
旧番号付きCoilエントリーはLRU回収を待つ。初回にURLキーの画像がなければ一度取得し直す費用を受け入れる。

番号付きキーを継続すると表示情報同期と画像取得の結び付きや通知との分断が残るため採用しない。
全画像キャッシュの削除も、ヘッダー・投稿添付・絵文字を余計に取得するため採用しない。

現在の動作は[アカウント・プロフィール仕様](../ui/accounts-profile.md#状態保持と画像の更新)、保存・呼び出し境界は[開発ガイド](../project-setup.md#画像キャッシュの更新)を参照する。
