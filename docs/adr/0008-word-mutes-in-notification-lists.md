# ADR 0008：通知欄のワードミュートとAndroid通知の適用範囲

- 状態：accepted
- 記録日・採用日：2026-10-06
- 継承元：[ADR 0005](0005-moderation-management-word-mutes.md)

## 背景

Issue #1でワードミュートに一致する返信が表示されると報告された。
当初は投稿の非表示に限定していたが、利用者は通知欄にも同じ判定を適用する方針を選んだ。
返信元からのAndroid通知を止める場合は、サーバーの通知抑制付きユーザーミュートを使う。

## 決定と理由

ADR 0005の管理専用ViewModel、管理対象の隔離、サーバー一覧と解除・取り消し、セッション別端末保存を継承する。
共通の表示フィルターで通知に含まれる投稿の本文・CWを判定し、通知欄の各タブへ適用する。
HTMLの表示テキスト化、部分一致、英字の大小を区別しない判定はタイムラインと共通にする。
投稿を含まない通知と通知者の名前はワード判定に使わない。
非表示通知は新着件数・強調表示・更新結果の新着判定から外すが、ページのカーソルは保持する。
ワードで隠す投稿・通知は内部一覧とDBに残し、解除や取り消しで再取得せず保持中の行を戻せる。
アカウント制限による除去は[ADR 0004](0004-account-moderation-invalidation.md)の方針を維持する。

Android通知へのワード判定と、Push本文を補う通知詳細の追加取得は導入しない。
返信元のユーザーミュートは利用者が明示的に実行し、ワード一致から自動設定しない。
通知を止めるユーザーミュートは既存のサーバー操作を使い、端末内のワードは同期しない。

## 代替案と受け入れる制約

Pushの短縮本文だけで判定する案は、本文やCWの見落としがあり通知欄と一致しない。
全文を追加取得してから通知する案は、通信失敗時の扱いと配信遅延の仕様が必要なため今回採用しない。
ワードに一致してもAndroid通知は表示される。アカウント全体の通知を止めたい場合はユーザーミュートを選ぶ。
サーバーのフィルター同期、ワードの別端末共有、全設定の定期同期は行わない。
