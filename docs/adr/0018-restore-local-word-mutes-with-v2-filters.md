# ADR 0018：公式フィルターv2と端末内ワードミュートを併用

- 状態：accepted
- 記録日・採用日：2026-10-12
- 置換元：[ADR 0017](0017-retire-local-word-mutes.md)

公式フィルターv2が利用できないサーバーでもワードによる非表示を利用できるよう、端末内ワードミュートの廃止を見直す。公式フィルターは`/api/v2/filters`のみを使い、v1の取得・移行・更新へのフォールバックは追加しない。対応判定はバージョン文字列によらず、v2一覧APIの応答で行う。既存実装と同じ404・405・501を未対応として扱い、通信・認証・その他の取得失敗や成功した空配列と区別する。

端末内機能は[ADR 0008](0008-word-mutes-in-notification-lists.md)の保存・表示方針を復元し、公式フィルターの取得状態とは独立して動作させる。アカウント別の旧`wordMutes`が設定JSONに残っていれば復元し、以後の保存で保持する。廃止版で既に除去されたワードは復元できず、再登録が必要になる。アカウント削除時はそのアカウントのワードも回収し、削除後の遅延保存を拒否する。

公式フィルターの取得失敗では最後の成功条件と取得日時を保持する。未対応表示から端末内の管理画面へ進める。端末内ワードは対応サーバーでも利用でき、本文・CWの部分一致判定をアプリ内の投稿・通知一覧に適用する。Android通知には適用しない。端末内ワードをサーバーへ自動送信・変換しない。

v1互換処理の追加は、条件・動作・編集契約を別途維持する必要があるため採用しない。端末内とサーバーの二つの管理経路を維持するコストは、v2未対応サーバーでも端末内機能を使えることを優先して受け入れる。

現行の表示・取得・保存仕様は[UIガイド](../ui-guidelines.md#サーバー保存設定と公式フィルター)と[開発ガイド](../project-setup.md#サーバー保存設定の同期)を参照する。
