# Nagisa

## アプリの紹介

<img src="app/src/main/res/mipmap-xxxhdpi/nagisa_launcher.png" alt="Nagisaのアプリアイコン" width="128" height="128">

Nagisaは、Android向けのMastodonクライアントです。
Mastodonのアカウントでログインして、投稿を読んだり書いたり、通知を確認したりできます。

異なるサーバーのアカウントを切り替えて使え、文字の大きさや操作ボタンも好みに合わせて調整できます。

現在はテスト用として配布しています。
各配布版の変更点は[GitHub Releases](https://github.com/ponpokoo/MastodonClient/releases)をご覧ください。

## 主な機能

| 機能 | できること |
| --- | --- |
| タイムライン | ホーム・ローカル・連合の閲覧、投稿の詳細と会話の表示、ストリーミングによる新着更新 |
| 探索 | トレンド投稿・ハッシュタグ・ニュースの閲覧、ハッシュタグの購読・解除、購読中タグの一覧 |
| アカウント | 複数アカウントの追加・切り替え・ログアウト。異なるサーバーにも対応 |
| 投稿 | 新規投稿・返信・自分の投稿編集、公開範囲・投稿言語の選択、内容警告（CW）、カスタム絵文字の挿入 |
| 引用 | 対応サーバーでの引用投稿・承認申請、本文への投稿URLの挿入による引用 |
| 添付・投票 | 画像・動画・共有からの音声添付、添付の説明（ALT）の入力、投票の作成・回答 |
| メディア再生 | 音声・動画の再生、一時停止・シーク・音量操作 |
| 下書き | 下書きの保存と呼び出し |
| 共有からの投稿 | Androidの共有メニューから、テキスト・URL・画像・動画・音声を取り込み。メディアの複数共有にも対応 |
| 投稿への操作 | お気に入り・ブースト・ブックマーク・共有、対応サーバーでの絵文字リアクション |
| 保存済み投稿・リスト | お気に入り・ブックマーク一覧、リストのタイムラインの閲覧、アカウントのリストへの追加 |
| 検索 | アカウント・投稿・ハッシュタグの検索 |
| 通知 | 通知一覧の閲覧・絞り込み、起動中の新着受信、定期確認通知、対応する配布版でのPush通知 |
| プロフィール | 固定投稿・投稿と返信・メディアの閲覧、プロフィールの編集、フォロー・解除、サーバーの設定・情報ページへの移動 |
| ミュート・ブロック・報告 | 投稿・プロフィールからの設定・解除・理由付き報告、設定からのミュート・ブロック一覧の閲覧・解除 |
| ワードミュート | アカウント別にワードを端末へ保存し、そのワードが本文やCWに含まれる投稿を非表示 |
| テーマ | ライト・ダーク・システム設定に合わせた表示 |
| 表示の調整 | 本文サイズ・行間・アイコンのサイズと形・サムネイルサイズ、投稿とタイムラインの操作ボタンの順序・表示の変更 |

使える機能や投稿の文字数、添付できるファイルの上限は、サーバーによって異なります。

## 動作条件

| 項目 | 条件 |
| --- | --- |
| 端末 | Android 8.0以上のスマートフォン |
| アカウント | Mastodonサーバーのアカウント |

Android通知を受け取るには、端末の設定でNagisaの通知を許可してください。

さまざまなMastodonサーバーで使えるように開発していますが、すべてのサーバーやバージョンで動作を確認しているわけではありません。

## インストールと初回設定

### インストール

1. Android端末で[GitHub Releases](https://github.com/ponpokoo/MastodonClient/releases)を開きます。
2. 配布版の説明と既知の制約を確認し、Assetsから`app-release.apk`をダウンロードします。
3. ダウンロードしたAPKを開いてインストールします。
4. インストールが完了したらNagisaを起動します。

テスト版にはPre-releaseと表示されています。
更新するときも、新しい配布版のAPKをダウンロードしてインストールしてください。

インストールの許可を求められた場合は、「この提供元を許可」を有効にしてください。
設定の表示名は端末によって異なります。

### ログインと設定

1. 「インスタンスのドメイン」に、アカウントのサーバーのドメインを入力します。
2. 「接続を確認」を押し、接続できたことを確認します。
3. 「ブラウザでログイン」を押します。開いたサーバーの画面でログインし、アプリの利用を承認します。
4. Nagisaへ戻り、タイムラインが表示されることを確認します。

ログイン後は、設定の「外観」「タイムライン表示」でテーマや文字の大きさを調整できます。
通知を使う場合は「通知」で受信方法を確認し、端末側でも通知を許可してください。
Push通知はアカウントごとに設定します。

別のアカウントを追加するには、設定の「アカウント管理」で「アカウントを追加」を選びます。
ログインの手順は初回と同じです。

## 基本の使い方

画面下部のアイコンから「ホーム」「探索」「通知」「プロフィール」を切り替えます。
ホームのタイトル右にある下向きアイコンから、ホーム・ローカル・連合を選べます。
探索・検索結果・通知・プロフィール内のタブは、タップか左右スワイプで切り替えます。
ホーム・探索・通知では、表示中の下部アイコンをもう一度押すと一覧の先頭へ戻ります。

探索ではトレンドや購読中のタグを確認できます。
検索語を入力したら、投稿・アカウント・ハッシュタグから対象を選び、キーボードの検索キーを押します。
タグの投稿一覧から購読でき、解除するときは確認画面が表示されます。

お気に入り・ブックマーク・リストは、自分のプロフィールの三点メニューから開けます。
引用するときは、投稿のブーストボタンを長押しして方式を選びます。
引用できる方式はサーバーの対応と投稿者の許可によって異なります。

ミュート・ブロックは投稿やプロフィールの三点メニューから設定・解除できます。
設定の「ミュート・ブロックの管理」では、ワードを追加・削除できます。
ミュート中・ブロック中の一覧を開いて解除することもできます。
管理画面でアカウントを選び直しても、タイムラインを閲覧するアカウントは変わりません。
ワードの追加・削除やミュート・ブロックの解除後は、通知に「取り消し」が2秒間表示されます。
「取り消し」を押すと、直前の変更を元に戻せます。

## 既知の制約

### 端末・サーバー

画面はスマートフォン向けです。タブレット専用の画面構成には対応していません。

検索結果や使える機能は、サーバーの種類・バージョン・設定によって異なります。
探索のトレンドやタグ購読、絵文字リアクション、引用投稿はサーバーの対応状況に従います。
投稿の全文検索の可否や検索範囲もサーバーによって異なります。

### 通知

通知が届く時刻は、通信状態や端末の省電力設定、バックグラウンドでの動作制限に左右されます。
定期確認は約15分ごとですが、通知が一定間隔で届くとは限りません。
初期設定では、バックグラウンドでストリーミングを停止しています。

Push通知を利用している場合も、定期確認通知がオンなら補助確認を行います。

### 下書き

下書きは手動保存です。編集中の内容を残すには、下書き保存を操作してください。

保存済みの下書きを呼び出すと、内容は編集中の投稿へ移ります。
再び下書きに残す場合は、もう一度保存してください。

### ワードミュート・ミュート・ブロック

ワードミュートは、この端末に保存したアカウント別の設定です。サーバーのフィルターは変更しません。
本文とCWの部分一致で投稿を非表示にし、通知・アカウント検索・添付のALTは対象にしません。

このアプリからのミュートは無期限で、対象からの通知も抑制します。
ミュート期間や通知抑制の有無を選ぶ画面はありません。
ブロック解除の取り消しで再ブロックしても、失われたフォロー関係は復元できません。

### 添付・投票

投票とメディアの添付は同時に使えません。
音声は他アプリからの共有で添付します。動画・音声は1件のみで、他のメディアと併用できません。
投票期間の選択と、添付ファイルの並べ替えには対応していません。
送信する画像の自動縮小・再圧縮は行いません。

## 不具合報告

不具合は[GitHub Issues](https://github.com/ponpokoo/MastodonClient/issues)へお知らせください。
アプリのバージョンは、設定の「このアプリについて」で確認できます。

通知の問題を報告する際は、Push・定期確認・ストリーミングの設定も添えてください。
また問題が起きたときにアプリを開いていたかどうかもお知らせください。
