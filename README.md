# Nagisa

<img src="app/release/google-play/icon-20261103/nagisa-app-icon-512.png" alt="Nagisaのアプリアイコン" width="128" height="128">

Nagisaは、Android向けのMastodonクライアントです。タイムラインを読んだり、画像やアンケートを添えて投稿したり、通知を受け取ったりできます。異なるサーバーのアカウントを切り替えて使え、文字の大きさや操作ボタンの配置も調整できます。

**[Google PlayでNagisaを入手する](https://play.google.com/store/apps/details?id=io.github.ponpokoo.mastodonclient)**

Android 8.0以上のスマートフォンとMastodonアカウントが必要です。

## 主な機能

| 機能 | できること |
| --- | --- |
| タイムライン・会話 | ホーム・ローカル・連合の閲覧、ストリーミングによる新着更新、長文の折りたたみ、投稿詳細での本文の範囲選択とコピー |
| 探索・検索 | トレンド投稿・ハッシュタグ・ニュースの閲覧、ハッシュタグの購読、アカウント・投稿・ハッシュタグの検索 |
| アカウント・プロフィール | 複数サーバーのアカウントの追加・切り替え、プロフィール編集、フォロー、固定投稿・返信・メディアの閲覧、注目のハッシュタグによる投稿の絞り込み |
| 投稿・下書き | 新規投稿・返信・編集・引用、公開範囲・投稿言語・内容警告（CW）の設定、カスタム絵文字の挿入とお気に入り登録、下書きの手動保存と呼び出し |
| 添付・アンケート | 画像・動画・音声の添付、代替テキスト（ALT）の入力、アンケートの期間・複数回答・結果表示の設定と投票 |
| 共有・メディア | Androidの共有メニューからテキスト・URL・メディアを取り込み、音声・動画の再生とシーク |
| 投稿への操作・一覧 | お気に入り・ブースト・ブックマーク・絵文字リアクション、保存済み投稿やリアクションした投稿の閲覧、リストのタイムラインの閲覧と登録アカウントの管理 |
| 通知 | 通知の種類別表示、同じ投稿への反応のまとめ表示、Push通知・定期確認・ストリーミングによる新着受信、サーバーからのお知らせの閲覧 |
| ミュート・フィルター | アカウントのミュート・ブロック、投稿やアカウントの報告、端末内のワードミュート、Mastodonのフィルター（v2）の管理 |
| 外観・操作 | ライト・ダーク・システム連動のテーマ、本文サイズ・行間・アイコン・サムネイルの調整、操作ボタンの表示や順序の変更、下部タブバーのフローティング・従来型・Liquid Glassの切り替え |

サーバーの種類・バージョン・設定によって、検索範囲、引用、絵文字リアクション、リアクション履歴などの利用可否や、投稿・添付・アンケートの上限が異なります。Liquid Glassのぼかし・屈折効果はAndroid 13以上で表示されます。

## はじめに

1. [Google Play](https://play.google.com/store/apps/details?id=io.github.ponpokoo.mastodonclient)からインストールします。
2. アカウントがあるサーバーのドメインを入力して接続を確認し、「ブラウザーでログイン」からアプリの利用を承認します。
3. Androidの通知を使う場合は、端末でNagisaの通知を許可し、アプリの設定で受信方法を選びます。Push通知はアカウントごとに設定できます。

詳しい操作は[使い方ガイド](https://ponpokoo.github.io/nagisa-policy/guide/index.html)をご覧ください。動画・音声は1件ずつ添付でき、音声は他のアプリの共有メニューから取り込みます。アンケートとメディアは同じ投稿に添付できません。
